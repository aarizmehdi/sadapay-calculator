## P0 Issues (MUST FIX)

### 1. Reverse Calculator not implemented
**File:** `src/components/CalculatorCard.tsx:110-118`
**Spec:** Line 25: "Reverse Calculator: PKR → USD equivalent"

The current implementation shows a "PKR Equivalent" label when USD is entered (line 111-118), but this is purely a display of the computed PKR amount. There is no way for the user to input PKR and get a USD equivalent back. This is an unimplemented spec feature.

**Fix:** Add a toggle/mode switch to the AmountInput to allow PKR input, then compute USD = PKR / sadapayRate.

### 2. No SadaPay logo — placeholder used instead
**File:** `src/app/page.tsx:9-11`
**Spec:** Component tree line 72: "Header (SadaPay logo + title)"

The header uses a generic placeholder `<div>` with an "S" letter instead of the SadaPay brand mark. No logo SVG exists in `public/`. This fails the spec's branding requirement for showing the actual SadaPay logo.

**Fix:** Add a SadaPay SVG logo to `public/` and render it in the header instead of the placeholder `<span>S</span>`.

## P1 Issues (SHOULD FIX)

### 3. Missing MarkupFee row in BankComparison
**File:** `src/components/BankComparison.tsx:63-106`
**Spec:** Component tree line 83: "├── MarkupFee"

The spec's component tree shows a separate `MarkupFee` row between `BaseAmount` and `TransactionFee` in the BankComparison column. The current component skips this row entirely — the 3% bank markup is baked into the `bankPkr` rate rather than shown as a distinct line item.

**Fix:** Calculate the bank markup as `bankPkr - (usd * marketRate)` and add a `Row` component for it between "Base Amount" and "International Fee".

## P2 Issues (Nice to Fix)

The file `sadapay-calculator/.env.example` does not exist. While no actual env vars are needed (no backend), the spec explicitly lists this file.
